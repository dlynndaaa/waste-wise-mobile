**WasteWise Mobile** is a smart waste management mobile application designed to help users monitor waste collection schedules, submit environmental issue reports, interact with an automated chatbot assistance service, and manage their user profile through a clean, eco-friendly interface.

---

## ✨ Key Features
- **🔐 Secure Authentication:** Login screen with account validation.
- **🏠 Interactive Dashboard:** Informative home screen featuring an eco-campaign image carousel and quick-access cards.
- **📅 Pickup Schedule:** Daily waste collection schedules categorized by regional zones.
- **📝 Report an Issue:** Environmental reporting feature complete with a submission status history tracker.
- **💬 Chat with Us:** Interactive support center with automated chatbot responses.
- **👤 User Profile:** User account page displaying contact information and a logout option.

## 🚀 Getting Started

Follow these steps to run or develop this project locally on your machine:

### 1. Prerequisites
Make sure you have installed:
- Node.js (LTS)
- npm or yarn
- Expo Go app on your physical mobile device (Android/iOS)

### 2. Clone the Repository
```bash
git clone https://github.com/dlynndaaa/waste-wise-mobile.git
cd waste-wise-mobile
```
### 3. Install Dependencies
```bash
npm install
```
### 4. Run the Application
It is recommended to use the tunnel mode for seamless connection from your mobile device:
```bash
npx expo start --tunnel -c
```
Scan the QR code displayed in your terminal using the Expo Go app on your phone.
